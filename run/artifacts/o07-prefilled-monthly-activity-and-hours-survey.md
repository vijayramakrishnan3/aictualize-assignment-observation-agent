# Prefilled Monthly Activity and Hours Survey

This is the field-by-field survey Financial Operations sends every RC manager each
month. It comes prefilled with last month's numbers and the Org Database position
list, so the manager only reviews, corrects, and confirms instead of rebuilding the
form from scratch.

## Fields

| Field | Where it comes from |
|---|---|
| RC number (4 digits) | Entered once, carried forward every month. |
| Position (Staff, Specialist, etc.) | Pulled from the Org Database dropdown. If a position you need is missing, call Shari Mao so the database gets corrected. |
| Activity | Pulled from the RC's existing activity list. If your team performs something not listed, contact Shari Mao for a copy of the Activity Dictionary before the deadline. |
| Physical (PH) or Financial (FI) | Required for Nat Gas activities. Mark which one applies to each line. |
| Last Month Hours | Prefilled automatically from the prior month's returned survey, summed across everyone in that position on that activity. |
| This Month Hours (draft) | Prefilled with the Last Month figure as a starting estimate. The manager overwrites it with the real number for the current month, or leaves it if nothing changed. |
| Confirmed Hours | The final number the manager signs off on and returns. |
| Standing report opt-out | If your RC already produces a report that captures this same data, check this box and send the report to Jennifer Reside and Shari Mao instead of filling out the rest of the form. |

## Example row, filled from a past survey

RC: {RC number}. Position: Specialist. Activity: {activity name from your Activity
Dictionary}. Driver type: PH. Last Month Hours: 40 (two specialists at 20 hours each
on this activity). This Month Hours (draft): 40, carried forward. Confirmed Hours:
{manager fills in after review}.

## How this replaces the current process

- The survey opens already carrying last month's hours and the current RC's roster
  from the Org Database, instead of a blank spreadsheet.
- The manager's job is to confirm each line or correct the ones that changed, not to
  re-estimate every position and activity from memory.
- Anyone who has not returned the survey by the deadline gets an automatic reminder,
  the same reminder Financial Operations currently sends by hand on the due date.
- If a position or activity is missing, the manager still calls Shari Mao or James
  Scribner to get it added, the same escalation path as today.

## When it changes

A new activity (EOL-related work, for example) needs the Activity Dictionary updated
before it can be prefilled. Until then, the manager adds it manually and flags it so
next month's prefill picks it up.
